## 二、逐文件讲解

### 2.1 monitor_inter.h —— 接口基类

```cpp
class MonitorInter
{
public:
    MonitorInter() {}
    virtual ~MonitorInter() {}

    virtual void UpdateOnce(monitor::proto::MonitorInfo* monitor_info) = 0;
    virtual void Stop() = 0;
};
```

| 代码 | 解释 |
|------|------|
| `virtual ~MonitorInter()` | 虚析构函数：通过基类指针 delete 子类时，会正确调用子类析构 |
| `= 0` | 纯虚函数：子类**必须**实现这个方法，否则编译报错 |
| `MonitorInfo*` | Protobuf 生成的消息类型，所有监控数据都填进这个结构 |

**这就是策略模式的"策略接口"。** 所有监控器继承它。

### 2.2 cpu_load_monitor.cpp —— 最简单的监控器

```cpp
void CpuLoadMonitor::UpdateOnce(monitor::proto::MonitorInfo* monitor_info)
{
    ReadFile cpu_load_file(std::string("/proc/loadavg"));  // ① 打开文件
    std::vector<std::string> cpu_load;
    cpu_load_file.ReadLine(&cpu_load);                     // ② 读一行，按空格分割

    load_avg_1_  = std::stof(cpu_load[0]);  // ③ 字符串转 float
    load_avg_3_  = std::stof(cpu_load[1]);
    load_avg_15_ = std::stof(cpu_load[2]);

    auto cpu_load_msg = monitor_info->mutable_cpu_load();  // ④ 获取 Protobuf 子消息
    cpu_load_msg->set_load_avg_1(load_avg_1_);             // ⑤ 填入数据
    cpu_load_msg->set_load_avg_3(load_avg_3_);
    cpu_load_msg->set_load_avg_15(load_avg_15_);
}
```

**逐行解释：**

| 行 | 干什么 | 为什么 |
|----|--------|--------|
| ① | `ReadFile` 构造时打开 `/proc/loadavg` | RAII：离开函数时自动关闭 |
| ② | 读一行，按空格分割 | `/proc/loadavg` 只有一行：`0.45 0.67 0.89 ...` |
| ③ | `std::stof` 字符串→浮点数 | C++11 标准函数 |
| ④ | `mutable_cpu_load()` | Protobuf 的 getter：返回子消息的可写指针 |
| ⑤ | `set_load_avg_1()` | Protobuf 的 setter：赋值 |

**`/proc/loadavg` 文件内容示例：**
```
0.45 0.67 0.89 2/345 12345
```
- `0.45` = 1 分钟平均负载
- `0.67` = 3 分钟平均负载
- `0.89` = 15 分钟平均负载
- 后面两个不重要

### 2.3 mem_monitor.cpp —— 字符串匹配

```cpp
void MemMonitor::UpdateOnce(monitor::proto::MonitorInfo* monitor_info)
{
    ReadFile mem_file("/proc/meminfo");       // ① 打开文件
    struct MenInfo mem_info;                   // ② 创建本地结构体

    std::vector<std::string> mem_datas;
    while (mem_file.ReadLine(&mem_datas))      // ③ 逐行读取
    {
        if (mem_datas[0] == "MemTotal:")       // ④ 匹配标签名
            mem_info.total = std::stoll(mem_datas[1]);
        else if (mem_datas[0] == "MemFree:")
            mem_info.free = std::stoll(mem_datas[1]);
        // ... 总共 19 个 if ...
        mem_datas.clear();
    }
    // ... 计算使用率，KB 转 GB ...
}
```

**逐行解释：**

| 行 | 干什么 | 为什么 |
|----|--------|--------|
| ① | 打开 `/proc/meminfo` | 这个文件包含内存全部信息 |
| ② | `struct MenInfo` | 有 19 个 `int64_t` 字段，存所有内存指标 |
| ③ | `while (mem_file.ReadLine(...))` | 逐行读，自动按空格分割 |
| ④ | 比较标签名 | `/proc/meminfo` 每行格式：`MemTotal: 16335784 kB` |
| ⑤ | `std::stoll` | string → long long（C++11） |

**计算公式（面试要背）：**
```cpp
// 使用率 = (总内存 - 可用内存) / 总内存 × 100%
mem_detail->set_used_percent(
    (mem_info.total - mem_info.avail) * 1.0 / mem_info.total * 100.0);

// KB 转 GB
mem_detail->set_total(mem_info.total / 1000000);
```

**为什么用 MemAvailable 而不是 MemFree？**
- `MemFree`：完全空闲的内存，很小
- `MemAvailable`：实际可用内存 = 空闲 + 可回收的缓存
- Linux 会积极用空闲内存做缓存，看 `MemFree` 会误判内存不足

### 2.4 cpu_stat_monitor.cpp —— 差分计算的核心

```cpp
void CpuStatMonitor::UpdateOnce(monitor::proto::MonitorInfo* monitor_info)
{
    ReadFile cpu_stat_file("/proc/stat");    // ① 打开文件

    std::vector<std::string> cpu_stat_list;
    while (cpu_stat_file.ReadLine(&cpu_stat_list))
    {
        if (cpu_stat_list[0].find("cpu") != std::string::npos)  // ② 找 CPU 行
        {
            struct CpuStat cpu_stat;          // ③ 填当前采样
            cpu_stat.cpu_name = cpu_stat_list[0];
            cpu_stat.user = std::stof(cpu_stat_list[1]);
            // ... 填 10 个字段 ...

            auto it = cpu_stat_map_.find(cpu_stat.cpu_name);  // ④ 找上次采样
            if (it != cpu_stat_map_.end())     // ⑤ 找到了 → 做差分
            {
                struct CpuStat old = it->second;  // ⑥ 取旧数据
                float new_total = cpu_stat.user + cpu_stat.system + ...;  // ⑦ 算总时间
                float old_total = old.user + old.system + ...;
                float diff = new_total - old_total;                         // ⑧ 差值

                if (diff > 0)
                {
                    // ⑨ 每种状态的变化量 / 总变化量 × 100% = 使用率
                    cpu_stat_msg->set_cpu_percent(
                        (new_busy - old_busy) / diff * 100.0);
                    cpu_stat_msg->set_usr_percent(
                        (cpu_stat.user - old.user) / diff * 100.0);
                    // ... 8 个百分比 ...
                }
            }

            cpu_stat_map_[cpu_stat.cpu_name] = cpu_stat;  // ⑩ 更新 map
        }
        cpu_stat_list.clear();
    }
}
```

**差分计算流程（核心中的核心）：**

```
第 1 次调用（t=0）：
    ┌─ 读 /proc/stat
    ├─ 解析 cpu_stat
    ├─ find("cpu0") → 没找到（第一次）
    ├─ 跳过差分
    └─ cpu_stat_map_["cpu0"] = cpu_stat  ← 存起来

第 2 次调用（t=3 秒后）：
    ┌─ 读 /proc/stat
    ├─ 解析 cpu_stat
    ├─ find("cpu0") → 找到了！
    ├─ old = map["cpu0"]
    ├─ diff_total = new_total - old_total
    ├─ 如果 diff > 0，计算 8 个百分比
    └─ map["cpu0"] = cpu_stat  ← 更新
```

**`/proc/stat` 的 CPU 行格式（10 个数字）：**
```
cpu  145598  1961  36646  11275927  3070  0  4478  0  0  0
     user    nice  system idle      iowait irq softirq steal guest guest_nice
```

**陷阱：`guest` 和 `guest_nice` 不要加进总时间**
```cpp
// ✅ 正确：不包含 guest 和 guest_nice
float total = user + nice + system + idle + iowait + irq + softirq + steal;

// ❌ 错误：包含了 guest，但 guest 已包含在 user 里，会重复计数
float total = user + nice + system + idle + iowait + irq + softirq + steal + guest + guest_nice;
```

### 2.5 net_monitor.cpp —— 差分 + 复杂文件格式

```cpp
void NetMonitor::UpdateOnce(monitor::proto::MonitorInfo* monitor_info)
{
    ReadFile net_file("/proc/net/dev");      // ① 打开文件

    std::vector<std::string> net_datas;
    while (net_file.ReadLine(&net_datas))
    {
        std::string name = net_datas[0];
        if (name.find(':') == name.size() - 1 && net_datas.size() >= 10)  // ② 过滤有效行
        {
            struct NetInfo net_info;
            name.pop_back();                           // ③ 去掉末尾的 ':'
            net_info.name = name;

            net_info.rcv_bytes = std::stoll(net_datas[1]);   // ④ 接收端
            net_info.rcv_packets = std::stoll(net_datas[2]);
            net_info.err_in = std::stoll(net_datas[3]);
            net_info.drop_in = std::stoll(net_datas[4]);

            net_info.snd_bytes = std::stoll(net_datas[9]);   // ⑤ 发送端（跳过 5-8）
            net_info.snd_packets = std::stoll(net_datas[10]);
            net_info.err_out = std::stoll(net_datas[11]);
            net_info.drop_out = std::stoll(net_datas[12]);

            net_info.timepoint = std::chrono::steady_clock::now();  // ⑥ 记时间

            auto iter = net_info_.find(name);  // ⑦ 差分同 CPU 监控
            if (iter != net_info_.end()) {
                double period = Utils::SteadyTimeSecond(...);
                if (period > 0) {
                    // 发送速率 (KB/s) = 字节差 / 1024 / 时间差
                    one_net_msg->set_send_rate(
                        (net_info.snd_bytes - old.snd_bytes) / 1024.0 / period);
                    one_net_msg->set_rcv_rate(
                        (net_info.rcv_bytes - old.rcv_bytes) / 1024.0 / period);
                }
            }
            net_info_[name] = std::move(net_info);  // ⑧ 更新历史
        }
        net_datas.clear();
    }
}
```

**`/proc/net/dev` 文件格式：**
```
Inter-|   Receive                              |  Transmit
 face |bytes packets errs drop ...压缩等... |bytes packets errs drop ...
  lo: | 1000   500    0    0    ...        | 1000   500    0    0    ...
 eth0: |20000  1000   5    2    ...        |15000   800    3    1    ...
```
- 前两行是表头，跳过（`name.find(':')` 检查过滤掉了）
- 有效行以 `接口名:` 开头
- 接收端：字段 1-8
- 发送端：字段 9-16

### 2.6 main.cpp —— 主循环

```cpp
int main(int argc, char* argv[])
{
    // 步骤 1：创建 5 个监控器
    std::vector<std::shared_ptr<MonitorInter>> runners_;
    runners_.emplace_back(new monitor::CpuSoftIrqMonitor());
    runners_.emplace_back(new monitor::CpuLoadMonitor());
    runners_.emplace_back(new monitor::CpuStatMonitor());
    runners_.emplace_back(new monitor::MemMonitor());
    runners_.emplace_back(new monitor::NetMonitor());

    // 步骤 2：连接服务器
    std::string server_addr = "localhost:50051";  // 默认地址
    if (argc > 1) server_addr = argv[1];          // 命令行参数优先
    monitor::RpcClient rpc_client_(server_addr);

    // 步骤 3：获取本机名字
    char* name = std::getenv("MONITOR_NAME");  // 环境变量
    if (!name) name = std::getenv("HOSTNAME");

    // 步骤 4：启动采集线程
    std::unique_ptr<std::thread> thread_(new std::thread([&]() {
        while (true) {
            monitor::proto::MonitorInfo monitor_info;
            monitor_info.set_name(std::string(name));  // 填主机名

            for (auto& runner : runners_)               // 所有监控器各跑一次
                runner->UpdateOnce(&monitor_info);

            rpc_client_.SetMonitorInfo(monitor_info);    // 发送
            std::this_thread::sleep_for(std::chrono::seconds(3));  // 等 3 秒
        }
    }));

    thread_->join();  // 永久等待（因为线程是死循环）
    return 0;
}
```

**执行流程：**
```
main 线程                        采集线程
  │                                │
  ├─ 创建 5 个监控器               │
  ├─ 创建 RPC 客户端               │
  ├─ 创建采集线程 ──────────────→  │
  │                                ├─ while(true) {
  │                                │    创建空消息
  │                                │    5 个监控器 .UpdateOnce()
  │                                │    RPC 发送
  │                                │    sleep(3秒)
  │                                │  }
  │                                │
  ├─ join() 永久阻塞               │
```

### 2.7 rpc_client.h —— gRPC 客户端

```cpp
class RpcClient {
public:
    explicit RpcClient(const std::string& server_address = "localhost:50051")
    {
        // 创建网络通道（非加密）
        auto channel = grpc::CreateChannel(server_address,
            grpc::InsecureChannelCredentials());
        // 从通道创建存根（Stub = 远程服务的本地代理）
        stub_ptr_ = monitor::proto::GrpcManager::NewStub(channel);
    }

    void SetMonitorInfo(const monitor::proto::MonitorInfo& monito_info)
    {
        grpc::ClientContext context;      // 请求上下文
        google::protobuf::Empty response; // 空响应
        grpc::Status status = stub_ptr_->SetMonitorInfo(
            &context, monito_info, &response);  // 远程调用！
    }
private:
    std::unique_ptr<monitor::proto::GrpcManager::Stub> stub_ptr_;
};
```

**关键概念：**
- **Stub**：gRPC 的"桩"，在本地址代表远程服务，调用 stub 的方法 = 调用远程方法
- **Channel**：TCP 连接，可以复用
- **ClientContext**：每次调用附带的元数据（超时、认证信息等）

### 2.8 rpc_manager.h —— gRPC 服务端

```cpp
class GrpcManagerImpl : public monitor::proto::GrpcManager::Service
{
public:
    grpc::Status SetMonitorInfo(...) override
    {
        std::lock_guard<std::mutex> lock(mutex_);  // 加锁！多线程安全
        monitor_infos_[request->name()] = *request;  // 按主机名存
        return grpc::Status::OK;
    }

    grpc::Status GetMonitorInfo(...) override
    {
        std::lock_guard<std::mutex> lock(mutex_);  // 每次方法都加锁
        *response = monitor_infos_[latest_host_];   // 返回最新主机的数据
        return grpc::Status::OK;
    }

private:
    std::mutex mutex_;                                          // 互斥锁
    std::unordered_map<std::string, MonitorInfo> monitor_infos_; // 主机名→数据
};
```

**关键点：**
- **为什么用 `std::lock_guard`？** 构造时自动加锁，析构时自动解锁。即使中途异常也不会死锁
- **为什么用 `std::mutex`？** gRPC 服务端是多线程回调的，多个客户端可能同时调 `SetMonitorInfo`
- **为什么用 `unordered_map`？** 按主机名存储，O(1) 查找

### 2.9 ReadFile —— RAII 文件读取工具

```cpp
class ReadFile {
public:
    explicit ReadFile(const std::string& name) : ifs_(name) {}  // 构造：打开文件
    ~ReadFile() { ifs_.close(); }                                // 析构：关闭文件

    bool ReadLine(std::vector<std::string>* args)
    {
        std::string line;
        std::getline(ifs_, line);                                // 读一行
        if (ifs_.eof() || line.empty()) return false;            // 结束了
        std::istringstream line_ss(line);                        // 字符串流
        while (!line_ss.eof()) {
            std::string word;
            line_ss >> word;                                     // 自动按空格分割
            args->push_back(word);
        }
        return true;
    }
private:
    std::ifstream ifs_;
};
```

**RAII 演示：**
```cpp
void some_function() {
    ReadFile f("/proc/stat");  // 构造：打开
    f.ReadLine();              // √ 正常读
    // 如果这里抛异常...       // 析构仍然执行！
    // return;                 // 正常返回也会析构
}   // ← 离开作用域，~ReadFile() 自动关闭文件
```
